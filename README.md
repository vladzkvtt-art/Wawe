## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки в корень репозитория.
2. В настройках репозитория откройте **Pages**.
3. В разделе сборки выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
4. GitHub выдаст адрес опубликованного сайта в разделе Pages.

Каталог книг, шрифты и PDF.js загружаются с внешних сервисов; для этих функций устройству пользователя нужен интернет.
